=====================================================================
            RINGKASAN PROYEK E-COMMERCE (MICROSERVICES)
=====================================================================

DESKRIPSI PROYEK
Proyek ini adalah implementasi backend untuk sistem e-commerce menggunakan arsitektur Microservices dan pola Backend-for-Frontend (BFF). 
Tujuannya adalah membangun sistem yang modular, skalabel, dan mampu menyajikan data yang optimal untuk berbagai jenis klien (Web, Mobile, Admin) secara efisien.

TEKNOLOGI UTAMA
- Framework: NestJS
- Database: MongoDB
- Arsitektur: Microservices & Backend-for-Frontend (BFF)

ALUR ARSITEKTUR
Client (Frontend) -> API Gateway -> BFF -> Microservices


=====================================================================
            DAFTAR LAYANAN (SERVICES) & PORT
=====================================================================

LAYANAN INFRASTRUKTUR
---------------------
API Gateway (http://localhost:8000)
Fungsi: Pintu gerbang utama. Menerima semua permintaan dari klien dan meneruskannya ke layanan yang sesuai.

BACKEND-FOR-FRONTEND (BFF)
--------------------------
BFF Admin (http://localhost:8008)
Fungsi: Menyediakan data yang sudah diolah khusus untuk kebutuhan dashboard admin.

BFF Web (http://localhost:8005)
Fungsi: Menyediakan data yang sudah diolah khusus untuk kebutuhan klien Web (Customer).

BFF Mobile (http://localhost:8006)
Fungsi: Menyediakan data yang sudah diolah khusus untuk kebutuhan klien Mobile (Customer).

LAYANAN MIKRO (MICROSERVICES)
-----------------------------
User Service (http://localhost:8001)
Fungsi: Mengelola data pengguna, alamat, otentikasi (login/register), dan otorisasi (roles).

Product Service (http://localhost:8003)
Fungsi: Mengelola data produk, kategori, stok, dan ulasan (reviews).

Order Service (http://localhost:8002)
Fungsi: Mengelola data keranjang (cart), daftar keinginan (wishlist), dan pesanan (orders).

Payment Service (http://localhost:8004)
Fungsi: Mengelola proses pembayaran dan konfirmasi untuk setiap pesanan.


=====================================================================
    ENDPOINT API: INFRASTRUKTUR & LAYANAN AGREGASI (BFF)
=====================================================================

--------------------------------------------------
API GATEWAY (http://localhost:8000)
--------------------------------------------------
Fungsi: Sebagai proxy yang meneruskan permintaan ke layanan BFF yang sesuai. Semua interaksi dari frontend harus melalui Gateway ini.

[ProxyController]

METHOD /api/(service-name)/(path)
Fungsi: Meneruskan permintaan ke layanan mikro atau BFF. Untuk akses ke BFF, gunakan nama layanan BFF.

Contoh Pola URL untuk mengakses BFF melalui Gateway:

Akses ke BFF Admin:
Gunakan prefix: http://localhost:8000/api/bff-admin/
Contoh: GET http://localhost:8000/api/bff-admin/dashboard

Akses ke BFF Web:
Gunakan prefix: http://localhost:8000/api/bff-web/
Contoh: GET http://localhost:8000/api/bff-web/dashboard

Akses ke BFF Mobile:
Gunakan prefix: http://localhost:8000/api/bff-mobile/
Contoh: GET http://localhost:8000/api/bff-mobile/home
